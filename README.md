# TUPPER

A brutalist, fully offline Windows workstation for **Tupper's self-referential
formula**. Import a bitmap, encode it into the 543-digit constant `k`, decode
any `k`, and fly through the `(x, y)` plane to find where the formula draws it.

Python 3.12 / PySide6 / Pillow / PyInstaller. No network calls, no telemetry.

Palette: black and white base, `#FF6A00` orange accent, `#3B2416` brown
secondary surfaces (controls, readouts, status bar). Sharp edges only: no
radii, gradients, shadows or easing.

## Download

Grab the prebuilt, fully offline Windows executable from
[Releases](https://github.com/piolunson/tupper/releases): `TUPPER.exe`,
no installer, no Python required.

## The formula

Jeff Tupper published this inequality in his 2001 SIGGRAPH paper on reliable
two-dimensional graphing:

```
1/2 < floor( mod( floor(y/17) * 2^( -17*floor(x) - mod(floor(y),17) ), 2 ) )
```

It is a complete 106 × 17 one-bit bitmap decoder. For `N = floor(y/17)` and
`r = mod(floor(y), 17)`, the cell at `(floor(x), floor(y))` is black exactly
when bit number `17 * floor(x) + r` of `N` is set. Restrict `y` to
`[k, k+17)` with `k = 17N` and you get a 106 × 17 image. Change one bit of `k`
and one pixel changes; any 106 × 17 image fits in a big enough integer.

### Orientation (important)

Plotted in the true mathematical plane (`x` right, `y` up), the formula's own
portrait is rotated 180°: upside-down and mirrored. Wikipedia's plot carries
the same footnote. The readable, canonical picture uses **both axes reversed**,
which is exactly what this app draws:

* display column `c`  = formula column `105 - c` (x = 0 is the right edge)
* display row `r`     = `mod(floor(y), 17)` (y = k is the top edge)

With that correction the original `k` plots itself; `tests/test_tupper.py`
pins the exact 17 rows so the orientation cannot regress. Encoding is the
inverse: bit index `17 * (105 - c) + r`.

## Features

**01 IMPORT** — file dialog, drag-and-drop, or `Ctrl+V` clipboard image.
Letterboxed to 106 × 17 preserving aspect ratio, grayscale, threshold slider,
Floyd–Steinberg or ordered Bayer 4/8 dithering, bitmap invert. The plate is a
live editor: left click draws, right click erases, dragging paints.

**02 ENCODE** — `k = 17N` recomputed on every edit, with a stepped typewriter
reveal, Copy, Save `.txt`, Load `.txt`, and a decoder field with presets
(original self-portrait, heart, invader).

**03 LOCATE** — the real formula, evaluated on big integers by background
workers, drawn as cached world-anchored tiles. The 106 columns stay framed
while the y axis zooms: wheel out to see the noise field of neighbouring
bitmaps (`k ± n`), wheel in to see individual cells. Drag pans; the orange
frame marks `x = 0..105 / y = k..k+16`. **FIND IMAGE** flies from y ≈ 0 to
`y = k` on a log-scale magnitude ladder, showing the actual bitmap at each
magnitude, then snaps onto the portrait.

Exports: nearest-neighbour PNG at ×8 / ×16, graph PNG including the frame and
axes, and `k` as plain text.

## Run from source

```
run.bat
```

or, with an existing environment:

```
python -m pip install -r requirements-dev.txt
python run.py
```

Python 3.12 is the target (3.12.10 used for the release build). The bundled
JetBrains Mono font is licensed under the SIL OFL; see
`assets/fonts/OFL.txt`.

## Build the exe

```
build.bat
```

The script creates `.venv` on Python 3.12 if needed, installs dependencies,
runs the test suite, and packages:

```
dist\TUPPER.exe
```

PyInstaller flags: `--onefile --windowed --icon assets\tupper.ico --add-data
"assets;assets"`. The exe embeds Python, PySide6, Pillow and the fonts, and
runs entirely offline.

## Tests

```
.venv\Scripts\python.exe -m pytest -q
```

Covers encode/decode round-trips (random, empty, full), the original k
rendering its own portrait, literal evaluation of the published inequality
against the bit path, anisotropic tile rasterisation, and the image pipeline
(letterboxing, thresholds, inversion, all dither modes).

## Notes on the graph

* Tiles are 216 px squares anchored in world coordinates, so panning reuses
  cached work; a QThreadPool renders missing tiles while the UI stays live.
* The x scale is clamped to the framed 106-column strip once zoomed out.
  Zooming out therefore grows the visible row range (other bitmaps) instead of
  collapsing the portrait into a one-pixel sliver.
* Neighbouring bands are near-copies of the portrait: adding 17 to `y` adds 1
  to `N`, which only flips the lowest bits, i.e. the rightmost columns. The
  noise becomes obvious further from `k`, which is what the zoom-out view
  shows.
* The status bar reports `X`, `Y = K + offset`, and the formula bit under the
  cursor; nothing in the graph is pre-baked.
